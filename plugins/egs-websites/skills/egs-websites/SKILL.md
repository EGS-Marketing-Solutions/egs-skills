# Websites

For whoever builds and revises client websites (in Duda), and any Claude helping them.

## The build order (EGS standard, 28 September 2026)

1. Internal review of the copy: content, SEO and account management.
2. The build.
3. The client reviews the live site and sends changes. Blogs keep document review.

Clients approve copy in a document and then ask for big changes once they see it live, so the live
review is the real one. Plan the time for it.

## Scope

- **Website build:** pages, design, forms, mobile, on-page basics, and schema on the core pages
  (home, about, contact, services, up to five). See the egs-seo skill.
- **SEO plan items** (not in a website build): backlinks, ongoing content, page speed programmes,
  conversion and AI citation tracking.

When a revision list arrives, sort it before doing anything.

## Build checklist, every page

- One H1; a title under 60 characters and a meta description under 155, both unique.
- Images compressed (WebP), sized to display width, with alt text.
- Phone number tappable; address and phone in the footer match the Google Business Profile.
- Forms tested end to end: submission arrives where it should (Amplify, inbox), confirmation shows.
- Booking links and buttons go somewhere real. Click every one.
- One tag container and analytics on every page; none on any page where a patient logs in or enters
  health details.

## Go-live checklist

- Every old URL redirects (301) to its new page.
- Sitemap submitted in Search Console; site verified.
- Core-page schema in place and tested.
- Mobile check on a real phone.
- The client has the live link and knows how to send changes.

## Produce automatically during the sweep

1. **Revision triage** for every new revision list: a table of each request, in scope or SEO plan or
   new work, effort, and the reply for anything out of scope, ready for the account manager.
2. **A page-by-page build checklist** for every site whose copy was approved since the last sweep.
3. **Meta titles and descriptions** for every page of a new build.
4. **The go-live checklist** filled in for any site due to launch this week, with what is still missing.
