# Slack

**For:** anyone who works with partners in a Slack workspace (for example an EHR partner's support
channel). **Time:** 2 minutes. **No API key.**

## Walk-through

1. claude.ai > Customize > Connectors > Slack > Connect.
2. Pick the Slack workspace and allow. Some workspaces need their admin to approve Claude first.

## Check

Ask Claude for the last messages in one channel they are in.

## Read-only

Claude reads Slack. Replies are posted by the person.
